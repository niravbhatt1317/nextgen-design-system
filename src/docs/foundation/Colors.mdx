# Colors

The Motadata color system provides a comprehensive palette designed for accessibility, consistency, and flexibility.

---

## Color Philosophy

Our color system is built on these principles:

- **Accessible:** All color combinations meet WCAG 2.1 AA standards
- **Consistent:** Semantic naming for predictable usage
- **Flexible:** CSS variables for easy theming
- **Mode-aware:** Automatic dark mode support

### Usage Guidelines

**Light Shades (10-40):** Backgrounds, borders, subtle highlights
**Mid Shades (50-80):** Secondary text, icons, disabled states
**Dark Shades (90-160):** Primary text, headings, high-contrast elements

**Example:**
```css
/* Light mode */
.card {
  background: rgba(246, 249, 252, 1); /* Neutral 10 */
  border: 1px solid rgba(227, 232, 242, 1); /* Neutral 30 */
  color: rgba(23, 35, 54, 1); /* Neutral 140 */
}

/* Dark mode */
.dark .card {
  background: rgba(23, 35, 54, 1); /* Neutral 140 */
  border: 1px solid rgba(43, 57, 79, 1); /* Neutral 110 */
  color: rgba(246, 249, 252, 1); /* Neutral 10 */
}
```

## Dark Mode

All colors automatically adapt to dark mode when the `.dark` class is applied to the root element.

### How to Enable Dark Mode

```tsx
// Toggle dark mode
document.documentElement.classList.toggle('dark');
```

## Customization

### Override Colors

Create a custom theme by overriding CSS variables:

```css
:root {
  /* Custom primary color */
  --mdt-primary: 142 71% 45%;  /* Green */
  --mdt-primary-foreground: 0 0% 100%;

  /* Custom destructive color */
  --mdt-destructive: 24 92% 55%;  /* Orange */
  --mdt-destructive-foreground: 0 0% 100%;
}

.dark {
  --mdt-primary: 142 71% 55%;
  --mdt-destructive: 24 82% 60%;
}
```

### Color Format

Use HSL format for all custom colors:

```
hsl(hue, saturation%, lightness%)
```

**Tips:**
- Keep saturation between 60-90% for vibrant colors
- Lightness 40-60% for dark mode backgrounds
- Lightness 90-98% for light mode backgrounds

## Accessibility

### Contrast Ratios

All default color combinations meet WCAG 2.1 AA standards:

- **Normal text:** 4.5:1 minimum contrast ratio
- **Large text:** 3:1 minimum contrast ratio
- **UI components:** 3:1 minimum contrast ratio

**Important:** Always test custom colors for accessibility before using them in production.
