# Spacing

The Motadata spacing system provides consistent spacing throughout the design system based on a 4px grid.

---

## Spacing Scale

All spacing values are multiples of 4px (0.25rem) for consistency.

| Token | Value (rem) | Value (px) | Usage |
| --- | --- | --- | --- |
| `mdt-0` | 0 | 0px | No spacing |
| `mdt-0.5` | 0.125rem | 2px | Tight spacing |
| `mdt-1` | 0.25rem | 4px | Extra small |
| `mdt-2` | 0.5rem | 8px | Small |
| `mdt-3` | 0.75rem | 12px | Medium small |
| `mdt-4` | 1rem | 16px | Medium |
| `mdt-5` | 1.25rem | 20px | Medium large |
| `mdt-6` | 1.5rem | 24px | Large |
| `mdt-8` | 2rem | 32px | Extra large |
| `mdt-10` | 2.5rem | 40px | 2X large |
| `mdt-12` | 3rem | 48px | 3X large |
| `mdt-16` | 4rem | 64px | 4X large |
| `mdt-20` | 5rem | 80px | 5X large |
| `mdt-24` | 6rem | 96px | 6X large |

---

## Usage Patterns

### Component Padding

- **Compact:** `mdt-p-2` (8px) - Dense layouts, small components
- **Default:** `mdt-p-4` (16px) - Standard components
- **Comfortable:** `mdt-p-6` (24px) - Cards, containers
- **Spacious:** `mdt-p-8` (32px) - Large sections

### Component Margins

- **Tight:** `mdt-mb-2` (8px) - Between related elements
- **Standard:** `mdt-mb-4` (16px) - Between components
- **Section:** `mdt-mb-8` (32px) - Between sections
- **Page:** `mdt-mb-12` (48px) - Between major sections

### Gap (Grid/Flex)

- **Tight:** `mdt-gap-2` (8px) - Compact grids
- **Default:** `mdt-gap-4` (16px) - Standard grids
- **Comfortable:** `mdt-gap-6` (24px) - Spacious layouts

---

## Usage Examples

### Padding

```tsx
// Small padding
<div className="mdt-p-2">Compact</div>

// Standard padding
<div className="mdt-p-4">Standard</div>

// Different padding on each side
<div className="mdt-px-4 mdt-py-2">Horizontal 16px, Vertical 8px</div>
```

### Margin

```tsx
// Bottom margin
<div className="mdt-mb-4">Element with bottom margin</div>

// Top and bottom margin
<div className="mdt-my-6">Element with vertical margin</div>

// Negative margin (use sparingly)
<div className="-mdt-mt-2">Negative top margin</div>
```

### Gap

```tsx
// Flex gap
<div className="mdt-flex mdt-gap-4">
  <span>Item 1</span>
  <span>Item 2</span>
</div>

// Grid gap
<div className="mdt-grid mdt-gap-6">
  <div>Item 1</div>
  <div>Item 2</div>
</div>
```

## Component Spacing Guidelines

### Buttons
- Padding: `mdt-px-4 mdt-py-2` (default)
- Gap between buttons: `mdt-gap-2` or `mdt-gap-3`

### Cards
- Padding: `mdt-p-6` (default)
- Gap between cards: `mdt-gap-4` or `mdt-gap-6`

### Forms
- Gap between form fields: `mdt-gap-4`
- Label to input: `mdt-mb-2`

### Lists
- Gap between list items: `mdt-gap-2` or `mdt-gap-3`

---

## Responsive Spacing

Use responsive prefixes to adjust spacing at different breakpoints:

```tsx
<div className="mdt-p-4 md:mdt-p-6 lg:mdt-p-8">
  Responsive padding: 16px → 24px → 32px
</div>
```

---

## Best Practices

### Do
- Use the spacing scale for consistency
- Keep spacing consistent within component groups
- Use larger spacing between unrelated sections
- Follow the 4px grid system

### Don't
- Use arbitrary spacing values
- Mix different spacing systems
- Use inconsistent spacing for similar components
- Overcrowd elements with too little spacing

---

## Custom Spacing

If you need custom spacing, extend the theme in `tailwind.config.js`:

```js
module.exports = {
  theme: {
    extend: {
      spacing: {
        '18': '4.5rem',  // 72px
        '22': '5.5rem',  // 88px
      },
    },
  },
};
```
