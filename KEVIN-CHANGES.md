# Kevin - Design System Changes

Branch `kevin`. One line per change.

- **2026-10-13 · Button `fixed` variant** - new `variant="fixed"`: the outline look (white fill, light border, dark label) that stays the same in light and dark mode, on 7 new `--mdt-fixed-*` tokens (no new colours); see Storybook → New Components → Button → Fixed.
- **2026-10-13 · ActionCard (new)** - the settings row card from the console mock (`MethodCard` / `.st-method`): `default`, dashed `add` and inline `edit` faces, `dim`, a badge and meta line, the full title in a tooltip on hover, and right-side slots for a switch, button or ⋯ menu; the whole card is clickable with `onClick` or `href` (`clickable={false}` turns it off) while the inner controls keep working on their own; see Storybook → New Components → ActionCard.
- **2026-10-13 · Button `dashed` variant** - new `variant="dashed"` for "+ Add tag" style actions: dashed blue border and label on no fill, solid border over a light blue fill on hover and when held on; uses the existing `--mdt-badge-info-ink` / `-fill` tokens, so dark mode follows; see Storybook → New Components → Button → Dashed.
- **2026-10-13 · Merged Pranjal's console-parts branch** - `pranjal/library-2026-10-13-console-parts` (12 parts, including `ConfirmDialog`) is merged into `kevin`, so the dialogs build on her `ConfirmDialog` instead of a second copy.
- **2026-10-13 · Dialog console header (default)** - every `Dialog` title is now 16/24 (was 18) with a line under the header (none when the header holds tabs), as the console draws it; `ConfirmDialog` drops its own copy of that styling.
- **2026-10-13 · SelectableCard (new)** - the console's option card (mock `ui/SelectableCard.jsx`): radio or checkbox at the top right, the whole card is the control, arrows move a radio set, a picker in the body keeps its own presses; stack, grid or chips; see Storybook → New Components → SelectableCard.
- **2026-10-13 · ConfirmDialog stories** - `DeleteWithReplacement` (holders banner, answer cards with an in-place picker, typed "delete") and `FormDialog` (Domain configuration: why panel with ticks, field, tip) join the existing notice and typed-delete stories, so all four console dialogs are shown.
- **2026-10-13 · Colours matched to the console** - ActionCard and SelectableCard quiet text now use `faint` (#8FA0BD) and the add-card blue `azure-60` (#0262DE), the exact colours the console mock draws; measured equal to the mock in light and dark.
- **2026-10-13 · Light tokens adopt the console's values** - `border` → neutral-20, `muted-foreground` → neutral-70, and neutral-70 (#8FA0BD), neutral-110 / neutral-150 (#1D2A3E), blue-10 (#F0F6FE), blue-60 (#0262DE), `feedback-info-bg` → blue-10, all as the mock's `global.css` sets them; measured equal to the mock in both themes, dark unchanged. Not taken: red-60 (the library keeps the ruled #DB132A, one unit off) and the info border #C9DDF7 (no ramp step; logged in MISSING-TOKENS.md). Note: muted text #8FA0BD on white is 2.65:1, under WCAG AA 4.5:1 (the old #727283 was 4.72:1).
- **2026-10-13 · Drawer** - `SheetContent` gains `closeOnOutsideClick`, `closeOnEscape` and `overlay` (with `size` 480/560/720/780, `side`, `inset`, and `modal={false}` on `Sheet`); new `SheetIdentity` (mark, name, status, meta lines, actions), `SheetSection` (heading, hint, action, hairline between sections) and `SheetField` (50/50 label · value row); the meta-line separator is now one shared helper for ActionCard and SheetIdentity; Storybook → New Components → Drawer shows the four console drawers and the closing options.
- **2026-10-13 · Drawer pages (generic in-drawer navigation)** - `SheetNavigation` + `SheetPage` + `SheetNavigationTitle` + `useSheetNavigation()` (`push`, `back`, `reset`, `current`, `depth`): Edit swaps the drawer's content in place, the header becomes the path with back ("User management › Edit details"), back returns, any depth; `useSheetLeaveGuard` lets a page ask "Discard unsaved changes?" first. The separate edit stories are gone - Edit inside each drawer story now uses this.
- **2026-10-13 · Drawer width in px or %** - `SheetContent` takes `width`: a number is pixels (`600`), a string is any CSS length (`'40%'`, `'600px'`, `'50vw'`; bare digits like `'600'` read as pixels); it wins over `size` and never grows past the screen. A width control is in Storybook → New Components → Drawer.
- **2026-10-13 · useForm (form validation for every form)** - `useForm({ initialValues, rules, onSubmit })` in the Form folder: `field(name)` binds an Input or Select (value, change, blur, error, required), `canSubmit` is the Save rule (something changed + every required field filled + not submitting), messages show when a field is left or Save is pressed (not while typing), a submit with a problem focuses the first bad field, `submitting` keeps Save busy, `reset()` after a save; `required` can depend on other values. Typed back to the start, Save turns off again. The drawer edit pages use it, with Save wired to the form through `form="id"`.
- **2026-10-13 · IconTile `outline` + copy button** - new `tone="outline"` (white, neutral-30 border, slate ink); give an IconTile `copyValue` (or `onClick`) and it becomes a button: hover lifts it over its neighbour with the console's subtle hover (neutral-40 border, neutral-10 fill, neutral-130 ink, Pranjal 2026-10-11 - not the old blue), a bubble shows the value (or `tooltip`) and `hint`, a click copies and the bubble says "Copied!" (`copiedLabel`), round tiles in a row overlap 6px. The table's `ContactChips` is now built on it instead of its own copy; Storybook → New Components → IconTile → Copy On Click.
